## Descrição do Projeto
Este repositório contém o teste prático solicitado pela DSIN, composto por 14 questões distribuídas em 9 páginas.  
O objetivo do teste foi desenvolver soluções baseadas em conhecimento próprio do candidato, priorizando lógica, organização e execução correta dos códigos.

O projeto inclui exemplos de algoritmos, scripts e soluções testadas, conforme instruções do teste.
